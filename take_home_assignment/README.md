# take_home_assignment

This folder contains the project code for the take-home assignment. Files added:

- `data/` - data loader
- `features/` - technical indicators and feature engineering helpers
- `strategies/` - strategy implementations (momentum, mean reversion, ML wrapper)
- `backtesting/` - backtest engine and metrics (already present)
- `utils/` - helper utilities
- `visualisation/` - plotting helpers

Run `main.py` to execute the basic strategy backtests. Install dependencies with:

```bash
python -m pip install -r requirements.txt
```
